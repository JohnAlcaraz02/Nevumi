The full picture

A little more capable.
In every direction.

From the file you just dropped to the idea you want to save. Here’s everything else Nevumi keeps within reach.

Understand your files.

  • Attach multiple PDFs, images, text documents, source-code files, or audio files by dropping them or using the file picker.
  • Summarize and explain supported content, ask questions about a document, or suggest a descriptive filename.
  • Extract text locally from images with OCR and from PDFs, including supported scanned pages. Text extraction doesn’t need Apple Intelligence.
  • Convert a single file or a batch, with output formats compatible with every file in the selection.

Give images a fresh start.

  • Enhance a photo’s tone, color, noise, and detail while keeping the original.
  • Remove a background automatically, or use erase and restore tools for finer control.
  • Replace the background with transparency, a solid color, blur, or another photo.
  • Describe a generated scene or ask for a background color in Quick Assistant. Generated scenes require supported Apple Intelligence features.
  • Save edits as PNG, JPEG, or TIFF.

Put it on your calendar.

  • Open the calendar composer or type a request such as “add dentist appointment tomorrow at 3 PM.”
  • Review the title, notes, date, time, all-day setting, and duration before saving.
  • Add the entry to your default macOS calendar. Nevumi asks for write-only access and cannot read existing events.

Keep the conversation going.

  • Ask general questions using Apple’s on-device model on supported Macs.
  • Follow up, make an answer shorter, or ask for more detail. Copy, save, share, or retry responses.
  • Ask about the current song or lyric. Mention “clipboard” to summarize or rewrite copied text.
  • Start a new conversation whenever you like. Optionally keep history on this Mac between launches.
  • Control Spotify with commands to play, pause, skip, or open a song search; built-in music commands don’t need Apple Intelligence.

Drop it. Send it. Done.

  • Drag files onto the notch and choose Convert or AirDrop, even when Spotify isn’t playing.
  • Pick a conversion format or open the system AirDrop window to share with a nearby device.
  • Reveal converted files in Finder, copy them, compress them into a ZIP, or rename a single output.
  • Set an after-conversion action to reveal, copy, or compress outputs automatically. Your choice is remembered.

At home on your Mac.

  • Lives in the menu bar, with an option to launch at login.
  • See the current Spotify track at a glance. The notch player hides when Spotify closes.
  • Enjoy fullscreen Sleep Mode or a music surface while the screen is locked. System sleep and lid closure are respected.
  • Customize window and screenshot shortcuts, or restore their defaults.
  • Style long screenshots with clean, dark, warm, paper, sage, and other backgrounds before copying or saving.

Your files stay close.File processing and supported assistant answers run on your Mac. Saved conversation history is local and opt-in. Clipboard text is read only when your request mentions it. Lyrics and artwork use the internet; AirDrop and cloud-calendar syncing use their own connections.

A few things to know

Before you settle in.

What do I need to run Nevumi?

A Mac running macOS 26 or newer. Spotify is required for the music controls and now-playing features. The notch player is designed around the physical MacBook notch.

Which features need Apple Intelligence?

General answers, file summaries, and writing help use Apple’s on-device model on a supported Mac with Apple Intelligence enabled. Generated image backgrounds also need supported Apple Intelligence features. Built-in Spotify and Sleep Mode commands, file conversion, text extraction, photo enhancement, background removal, window shortcuts, and long screenshots work without general assistant answers.

Does Sleep Mode put my Mac to sleep?

Sleep Mode is a fullscreen music and lyrics experience. It does not mean system sleep. Click or press a key to dismiss it.

Can I buy Nevumi now?

Not yet. The planned paid release will offer a free 14-day trial, a $15 USD early-access license, and a $25 USD standard price. The current download is a free development preview, not the timed trial. Checkout and purchase terms will appear here when sales open.

What should I know about the preview build?

This download contains Nevumi version 0.1.1 as a universal disk image for Apple silicon and Intel Macs. It is a development preview and has not been notarized by Apple, so macOS may warn or block it from opening. Open the disk image and move Nevumi to Applications. A polished public release is still to come.

What permissions does Nevumi use?

Automation lets Nevumi control Spotify. Screen Recording is used for long screenshots, Accessibility for window control, and write-only Calendar access for entries you choose to save. Nevumi cannot read your existing calendar events. Clipboard text is read only when your assistant request mentions “clipboard.”

How do I capture a long screenshot?

Press Control–Option–S, select the scrolling content, then scroll down slowly with overlapping sections. Leave fixed toolbars outside the selection and keep the window at the same size. Choose Finish to edit, copy, or save the capture. Capture stops before 30,000 pixels or after 80 sections.

How does file drop at the notch work?

Drag a file to the notch, then move over Convert or AirDrop. Release over Convert to choose an output format, or over AirDrop to send it through the macOS sharing window. For summaries, image editing, and other file actions, attach the file in Quick Assistant instead.

Where do the lyrics come from?

Nevumi fetches lyrics from LRCLIB. Synchronized lyrics appear when a matching entry is available for the current song. Artwork and lyrics require an internet connection.
